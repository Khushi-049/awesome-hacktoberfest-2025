# 🎯 Memory Flip Game

A fun and colorful card matching game built with **HTML, CSS, and JavaScript**.

## ✅ Features
- Cute Emoji Pairs 🐼🐸🐯🍉
- Flip Animations
- Score Counter (Moves Count)
- Restart Button
- Fully Responsive Design 📱

## 🎮 How to Play
Click the cards to reveal emojis — match pairs 🎯  
The fewer moves you take, the better!

---

### 🔄 Restart Anytime
Click **Restart Game** to shuffle and start fresh.
